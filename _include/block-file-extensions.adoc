「區塊可疑檔案副檔名」選項會使用您為組織設定的預設清單。若要link:task-file-extensions.html["使用自訂清單"]您建立的清單，請選取鉛筆圖示。

+ 如果您已在 ONTAP 中設定了封鎖的檔案副檔名清單，您可以透過選擇 *以 Ransomware Resilience 清單取代 ONTAP 清單* 來置換這些清單。然後選擇您要 SVM *允許除封鎖清單以外的所有檔案副檔名* 還是 *區塊除允許清單以外的所有檔案副檔名*。然後，從下拉式選單中選擇清單。工作負載上的所有儲存設備虛擬機器（SVM）都將使用該清單；您稍後可以將不同的清單套用至工作負載上的不同 SVM。
