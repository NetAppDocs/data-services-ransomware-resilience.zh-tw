=== 透過 Console 代理程式交付 SIEM 事件

除了現有的透過 NetApp Console 交付事件的選項外，勒索軟體復原功能現在還支援透過 Console 代理程式交付 SIEM 事件。

透過 Console 代理程式交付 SIEM 事件時，您可以將 SIEM 事件交付限制在網路邊界內。這簡化了具有嚴格 IP 位址允許清單的本地環境的部署，並能更好地遵守現有安全性控制。若要使用此選項，請確保 Console 代理程式能夠透過任何防火牆或 Proxy 控制，解析並連線至所需連接埠上的 SIEM 端點。

如需詳細資訊，請參閱 link:https://docs.netapp.com/us-en/data-services-ransomware-resilience/task-siem.html["設定 SIEM 系統"^]。
