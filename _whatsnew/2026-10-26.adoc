== 建立使用者活動代理程式的新手冊工作流程

Ransomware Resilience 現在提供手冊建立使用者活動代理程式的工作流程，讓您能進一步控制在 VM 上建立使用者活動代理程式的方式。透過此新工作流程，您可以直接安裝使用者活動代理程式並設定 Proxy 設定，而無需提供 VM SSH 金鑰。

如需詳細資訊，請參閱 link:https://docs.netapp.com/us-en/data-services-ransomware-resilience/suspicious-user-activity.html#create-a-user-activity-agent["建立使用者活動代理程式"^]。
